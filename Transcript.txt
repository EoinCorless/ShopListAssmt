## Conversation transcript

**You:** How could I run this App?

**Assistant:** This is a native Android app. The project is in `ShopListAssmt`.

**Run it in Android Studio**
1. Install Android Studio and make sure JDK 17 and Android SDK Platform 35 are available.
2. Open the `ShopListAssmt` folder in Android Studio and wait for Gradle sync.
3. Start an emulator (Android 8.0 / API 26 or newer) or connect an Android device with USB debugging enabled.
4. Select the app’s run configuration and click **Run**.

Or, from PowerShell in the project folder, run `.\gradlew.bat :app:installDebug`. To build without installing, run `.\gradlew.bat :app:assembleDebug`. The APK is under `app\build\outputs\apk\debug\`.
